## Purpose

OpenImageR is an R package for image preprocessing, filtering and image
recognition (version 1.3.0, GPL-3). Computationally heavy functions are
implemented in C++ with RcppArmadillo (OpenMP enabled via Makevars).
Images are plain R matrices (grayscale) or 3-dimensional arrays (RGB).

## Main methods (exported)

- I/O: readImage(), writeImage(), load_binary(), verify_image_extension(), imageShow()
- Basic transforms: resizeImage(), rotateImage(), rotateFixed(), flipImage(),
  cropImage(), translation(), padding(), down_sample_image(), rgb_2gray(),
  RGB_to_HSV(), RGB_to_Lab()
- Filtering / preprocessing: convolution(), uniform_filter(), edge_detection(),
  gamma_correction(), image_thresholding(), dilationErosion() (and the deprecated
  spelling delationErosion()), ZCAwhiten(), NormalizeObject(), MinMaxObject(),
  norm_matrix_range(), List_2_Array()
- Augmentation: Augmentation()
- Feature extraction: HOG(), HOG_apply(), GaborFeatureExtract (R6 class)
- Image hashing: average_hash(), dhash(), phash(), invariant_hash(), hash_apply()
- Superpixels: superpixels() (SLIC / SLICO), superpixel_bbox(), superpixel_bbox_subset()
- Geometry: getAffineTransform(), warpAffine()
- Shiny: an image-viewing shiny app under inst/shiny_app (R/launcher_shiny.R)

## Structure

- R/: R wrappers and input validation; RcppExports.R is generated by Rcpp
  (do not edit by hand). One file per topic (hash_functions.R, superpixels.R,
  gabor_feature_extraction.R, warp_affine.R, read_image.R, write_image.R, ...).
- src/: Rcpp / RcppArmadillo code. All exported C++ functions live in
  src/extract_inst_folder_headers.cpp; RcppExports.cpp and init.c are generated.
  Makevars adds -DARMA_64BIT_WORD, OpenMP flags and -I../inst/include/.
- inst/include/: header-only C++ (OpenImageRheader.h with the main
  implementations, SLIC.h and SLICO.h for superpixels). These headers are also
  installed so other packages can LinkingTo OpenImageR.
- inst/COPYRIGHTS: third-party code attributions (SimpleCV HOG, ImageHash,
  Gabor Matlab code, SLIC/SLICO, WarpAffine).
- tests/testthat/: one test file per feature; sample images in
  tests/testthat/image_files.
- vignettes/, man/ (roxygen2 7.2.3 generated), NEWS.md.

## How to test

Never install this workspace version into the R library. Use:

```r
devtools::load_all("/home/lampros/add_GITHUB/OpenImageR-improvements")
devtools::test("/home/lampros/add_GITHUB/OpenImageR-improvements")
```

Full check (from the parent folder):

```sh
R CMD build OpenImageR-improvements
R CMD check --as-cran OpenImageR_1.3.0.tar.gz
```

After editing C++ with // [[Rcpp::export]] or roxygen comments, run
Rcpp::compileAttributes() and devtools::document() in the workspace.
